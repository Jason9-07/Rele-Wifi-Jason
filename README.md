Rele Wifi - ESP8266

  En este proyecto el ESP8266 se logro su funcionamiento. Tiene como propósito funcionar en proyectos de detección de temperatura en tanques de agua, con el finde asegurar de tener el recipiente lleno dependiendo de los datos que se le asigno, regular la temperatura y dar aviso de cualquier falla del funcionamiento como de falla de regulación de agua, sobre aumento de liquido o sustancia que contenga.
